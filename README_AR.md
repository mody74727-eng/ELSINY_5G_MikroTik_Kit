# ELSINY_5G — حزمة تجهيز MikroTik Container (x86_64)

هذه الحزمة تنقل تطبيق ELSINY_5G الحالي (Flask + Paramiko) إلى Linux Container ليعمل على MikroTik x86_64. التطبيق الحالي يفحص أجهزة OpenWrt عبر SSH؛ لا يدّعي أنه يقرأ منافذ RouterOS المحلية مباشرة.

## ما تم تجهيزه
- صورة Linux مبنية على Python 3.12 ومناسبة لـ `linux/amd64`.
- التطبيق يستمع داخل الكونتينر على `0.0.0.0:7070`.
- ملف الإعدادات وكلمات المرور يبقيان في مجلد بيانات دائم `/data/ELSINY_5G_settings.json`.
- واجهة ELSINY_5G الداكنة، ألوان سرعات المنافذ، وفرز hostname/IP.
- اختصارات: `Ctrl+Enter` للفحص، `Ctrl+,` للإعدادات، `Esc` لإغلاق نافذة الإعدادات.
- فحص صحة داخلي على `/healthz`.

## بناء ملف الصورة على كمبيوتر Windows
1. ثبّت Docker Desktop وشغّله.
2. فك ضغط الحزمة.
3. شغّل `BUILD_IMAGE.bat`.
4. سينتج الملف `ELSINY_5G_mikrotik.tar` بجانب ملف BAT.
5. ارفع ملف TAR إلى MikroTik من WinBox > Files.

يمكن استخدام `BUILD_IMAGE.sh` على Linux.

## ملاحظة مهمة عن العنوان الذي اخترته
`127.14.14.1` عنوان Loopback. أي جهاز يفتح هذا العنوان سيصل إلى نفسه، وليس إلى MikroTik. لذلك لا يمكن استخدام `http://127.14.14.1:7070` من كمبيوتر أو هاتف آخر للوصول إلى الراوتر. التطبيق سيعمل على المنفذ 7070 داخل الكونتينر، وبعد تحديد عنوان إدارة قابل للوصول نضيف قاعدة تحويل منفذ محصورة على شبكة الإدارة. لن نغيّر عنوان الهوتسبوت أو WAN.

## لا تنفّذ إعداد RouterOS بعد
لم نحدد بعد مسار تخزين دائم موثوق؛ `/disk print` السابق أظهر slots فارغة، مع أن `/system resource` أظهر مساحة حرة كبيرة. كما لم تصلنا بعد قواعد firewall filter التفصيلية. يلزم مراجعة هذين الأمرين قبل إضافة veth أو NAT أو Container، لتجنب قطع الإنترنت أو تعريض لوحة التحكم.

## بيانات الدخول الافتراضية للتطبيق
- Username: `admin`
- Password: `admin`

غيّر كلمة المرور فور أول دخول. كلمة مرور SSH تحفظ في ملف الإعدادات داخل مجلد البيانات الدائم؛ احمِ هذا المجلد ولا تشارك نسخة منه.

## أوامر فحص آمنة
يمكن نسخ محتوى `RouterOS/READ_ONLY_CHECKS.rsc` إلى Terminal؛ جميع الأوامر للقراءة فقط.

## بديل بدون Docker محليًا
إذا لم يتوفر Docker على الكمبيوتر، يمكن بناء الصورة على GitHub Actions. راجع `BUILD_WITH_GITHUB_AR.md`، وارفع محتويات المجلد إلى مستودع GitHub ثم شغّل workflow باسم `Build ELSINY_5G MikroTik image`. سيظهر ملف `ELSINY_5G_mikrotik` في Artifacts.
